Introduction

Smart Fridge is an IoT project that monitors the refrigerator door and internal temperature. It helps users know when the door is left open or the temperature becomes too high.

Problem Statement

Sometimes, users forget to close the refrigerator door. This can waste electricity and increase the temperature inside the refrigerator.

Project Objectives

  • Monitor the refrigerator door.
  • Measure the internal temperature.
  • Give an alarm when a problem occurs.
  • Send alerts to the user using Telegram.
  • Display the system status on a web page.

Proposed Solution

The system uses sensors connected to an Intel Galileo board. The board checks the sensor readings and activates a buzzer when the door stays open for too long or the temperature exceeds the allowed limit.

Benefits

  • Reduce electricity waste.
  • Keep the refrigerator temperature under control.
  • Notify users about possible problems.

Intended Users

This project can be useful for families, homes, and small businesses that use refrigerators.
