System Components

  • Intel Galileo: Processes sensor readings.
  • Magnetic Reed Switch: Detects if the door is open or closed.
  • DS18B20 Sensor: Measures the temperature.
  • Buzzer: Gives a local warning.
  • Telegram Bot: Sends alerts to the user.
  • Web Dashboard: Displays the system status.

System Diagram

How It Works

  1. The sensors read the door status and temperature.
  2. Intel Galileo checks the readings.
  3. If a problem is detected, the buzzer gives a warning.
  4. A Telegram message can be sent to the user.
